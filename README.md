# 치이카와 FPS 온라인 UI 업데이트
제공된 3장의 이미지를 배경으로 실제 DOM 버튼/슬롯/입력창을 올린 비공식 팬 게임입니다. 예시 코드와 선택 상태는 불투명 패널로 덮고 실제 서버 상태를 표시합니다.
## Render 업데이트
기존 저장소의 server.js, index.html, package.json, render.yaml을 교체하고 maps.json을 새로 추가하세요. 폴더 없이 5개 파일이 저장소 루트에 있어야 합니다. Render 자동 배포 완료 후 참가자 모두 새로고침합니다. 기존 방은 초기화됩니다.
설치 npm install / 실행 npm start. Render의 PORT 환경변수를 사용합니다. plan: free 설정입니다.
## 기능
실제 서버가 생성하는 6자리 코드, 사람/AI 공용 팀 슬롯, 방장만 AI 추가/제거/설정/시작, 모드/맵별 랜덤 및 맵 투표, 아군 픽 공개/상대 픽 숨김, 모두 준비 후 전투 시작.
거점/섬멸/화물/당근 설치/팀 데스매치에 각각 2개 전장이 있습니다. 선택한 모드에 맞는 전장만 표시됩니다. 모드 랜덤이면 전체 전장에서 투표 후보를 무작위 선정합니다. 특정 맵 지정 시 후보는 해당 맵 1개입니다.
## 규칙
3라운드 선승. 거점: 단독 점령 100%. 화물: 블루 호위/레드 저지, 제한시간 4분. 당근: 중앙 구역에 블루 3초 머물러 설치, 40초 후 폭발, 레드 5초 머물러 해체. 섬멸과 당근은 라운드 중 부활 없음. 그 외 3초 후 고정 기지 부활. 팀 데스매치 25킬.
## 제한 및 테스트 범위
HTML을 다운로드해 열면 메인/코드 입력 화면은 볼 수 있지만 방 생성과 전투는 서버 배포가 필요합니다. 실제 Render 배포/다중 브라우저 테스트는 수행하지 않았습니다. 자동 재접속, 계정, 영구 저장, 고급 치트 방지는 없습니다. 역할군 분류는 UI용이며 역할군 전용 스킬은 없습니다. 온라인 궁극기/수동 회복 스킬은 비활성화, 기지 회복은 서버 적용입니다.
